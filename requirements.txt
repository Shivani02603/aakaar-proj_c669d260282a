**Primary Users:** End users who upload Excel files and ask natural-language questions about the data  
**Tech Constraints:** Python FastAPI (backend), Next.js (frontend), PostgreSQL with pgvector extension, Docker Compose for deployment, OpenAI text-embedding-3-small, Google Generative AI SDK (gemini-2.0-flash)

**Project Summary:** This project builds a web application that allows users to upload Excel (.xlsx) files and ask natural-language questions about the data. The system ingests Excel files by parsing them with pandas, chunking the content, embedding chunks with OpenAI, and storing vectors in pgvector. On query, it retrieves relevant chunks via cosine similarity and uses Google Gemini to generate answers with source citations, all within named chat sessions stored in PostgreSQL.
